# Focused reference review

The four repository READMEs and available license metadata were reviewed. Deeper code inspection was limited to Neon Mayhem (city worker) and Sketchbook (camera structure). No source or assets from these projects were incorporated; implementation is original within the existing Three/Fiber architecture. None were run locally: building the actual Cruise proof resolved the relevant compatibility/visual questions without porting an engine. Their performance claims are not measurements on this computer.

| Reference | Useful technique / compatibility | Terms and decision |
|---|---|---|
| [Spiderbench](https://github.com/xikhar/spiderbench) | Time-of-day presets and an authored street network are relevant. The README's GI/AO/reflections/TAA/motion-blur stack recommends a discrete GPU and is not demonstrated suitable for this Intel UHD target. | [View-only license](https://github.com/xikhar/spiderbench/blob/main/LICENSE) forbids product incorporation. No code/assets copied; rejected effects stack and local port. Retained existing physically based materials and controlled lighting. |
| [Neon Mayhem](https://github.com/pranshuparmar/neon-mayhem) | Recognizable commercial clusters, restrained facade palettes and context-sensitive guidance. Original corridor-based translation; see CITY-REFERENCE.md for exact modules. | Apache-2.0 repository, vendored Three has separate MIT notice. No source/assets reused. Existing internet radio remains, rather than synthesized stations. |
| [Sketchbook](https://github.com/swift502/Sketchbook) | Inspected `src/ts/core/CameraOperator.ts`: camera target/radius separated from the input receiver. Adopted that separation concept with a dedicated focus state, target interpolation and prior-camera restoration; control dragging never enters camera-look input. | [MIT](https://github.com/swift502/Sketchbook/blob/master/LICENSE), archived October 2024. No copied code or bundled Blender assets. Rejected Cannon/vehicle engine migration. |
| [Spider-Man NYC](https://github.com/SBhat2026/spider-man-nyc) | README describes chunks, frustum culling and instancing. Applied conventional bounded corridor pooling and visibility culling independently; no Manhattan data needed for a Miami-inspired route. | No repository LICENSE shown in root metadata; OSM data has separate attribution/licensing obligations. Code/data permission not established; no code/data/assets reused. The README's ~360 draw-call claim is unverified here. |

Physical references: the user's existing `turo_wrangler_islander_jpg/08_interior_dash.jpg`, seating and exterior photos. These were viewed as design/proportion references, not distributed as textures. See JEEP-ASSET.md for two model candidates and the original vehicle's provenance.

Existing analytics inspection found only `lib/cruise/analytics.ts`'s bounded diagnostic buffer plus optional `window.gtag` forwarding. No initialized GA client or already authorized collection endpoint was found in app/lib/components. The interface is preserved; production ingestion remains unconfigured. No test counts are presented as an audience.
