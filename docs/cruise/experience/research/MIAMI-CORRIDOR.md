Phase2 lifts only Countach and Wrangler cockpit gaze modestly; radio focus, eye position, chase poses and all original route profiles stay exact. Nearby existing landmarks gain an optional inspection affordance; selecting one parks the car and uses the existing landmark camera, then returns to prior park state. No extra city meshes, new textures, assets or paid services.

The experience route accepts `?sunsetMinutes=30` through `45`, default40; invalid inputs use40. Simulation pause also pauses the transition. Night remains immediate. Six pure tests verify duration validation, clamping, invalid clocks and camera preservation.

This is a composition refinement of the successful world, not a claim of photorealism or newly reconstructed architecture. Street geometry, some repeated facade details and vehicle windshield framing still limit perceived realism. Future asset work should target one measured hero stretch after physical mobile and load tests; avoid expanding the memory footprint blindly. Existing chunks remain retained after generation, so full-loop memory growth needs a longer soak before public launch.
