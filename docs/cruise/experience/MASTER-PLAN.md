## Phase sequence and gates

1. **Opening minute:** new opt-in `/cruise/experience` route. Actual Miami scene behind a single Start Cruising action; optional ride choice secondary. Start audio on gesture, unobtrusive radio, natural cockpit reveal with manual override/reduced-motion respect, no automatic radio changes. Test a moving90-second path and audio/cameras before phase2.
2. **Miami stretch:** retain the full19,642.96m connected route. Use Colony, Breakwater, Clevelander, Carlyle and Leslie as the five existing geographic anchors. Improve sightlines/hero detail selectively, preserve mapped footprints and sunset/night. Profile/measure before accepting render cost; transition duration bounded30–45minutes. No new city or engine.
3. **Effortless discovery:** reuse Human Radio. Add fast station seek, searchable directory and return-to-manual-presets behavior where missing; maintain provenance, fallback and audio ownership. Repair only supported endpoints; no paid recognition. Run focused radio/persistence and failure checks.
4. **Distribution and honest measurement:** capture actual canvas pixels into an attributed silent PNG postcard with direct scene/station link. Optional existing presence with explicit lease handling. Consent-based, bounded metrics and internal/local reporting; never collect song/artist taste or fabricate audiences. Preserve ad systems and keep the first minute clear. Test exports, opt-out, validation and presence expiry.
5. **Playtest package:** three X hooks, authentic12–18second capture plan, invitation/feedback, reporting instructions and prioritized backlog. No public deploy or claimed human playtest without actual participants.

Critical regressions stop phase progression until fixed. Feature gaps that need external services/devices are recorded as blockers rather than simulated successes.
