Scope and limits: source/configuration review, focused API/auth/upload regressions, local PostgreSQL policy execution, tracked text secret scanning, authorized Vercel configuration/deployment, webhook registration, live Supabase access controls, legacy Cloudflare retirement and bounded hosted checks. Full secret history, all external-provider IAM/storage settings, physical device/Cast playback and a full browser penetration test are outside the verified evidence. The CSP deliberately leaves scripts/connections unrestricted to preserve existing media/payment functionality; it is not a claim of comprehensive XSS prevention. File signature checks reject obvious type confusion; they are not malware scanning. The local-only IMG.LY/Zod advisory remains documented in the dependency report.
